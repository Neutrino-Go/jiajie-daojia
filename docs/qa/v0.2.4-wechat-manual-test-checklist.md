## 1. v0.2.1/v0.2.2/v0.2.3 回归

- [ ] 小程序可正常启动，无白屏和明显 `ReferenceError`。
- [ ] 前端没有 `ENABLE_MOCK_PAYMENT`。
- [ ] 前端不调用 `mockPayOrder`。
- [ ] 页面没有“平台托管中”“支付到平台托管”“费用已由平台托管”。
- [ ] 页面没有“百万保障”“全额赔付”“已投保”。
- [ ] 公开订单列表不显示客户手机号、微信号、详细地址、备注、customerOpenid、完整 responses。
- [ ] 售后 claim 详情仍按订单参与方权限隔离。
- [ ] 报价和下单仍使用服务端 quote，不信任前端金额字段。

## 2. 家洁师 Trust Profile

- [ ] 管理员可将家洁师标记为 blocked。
- [ ] blocked 家洁师不能响应公开订单。
- [ ] 管理员可解除 blocked 家洁师。
- [ ] 管理员可调整 trustScore。
- [ ] trustScore 低于 50 时，家洁师应被降权或标记为低信任。
- [ ] trustScore 低于 30 时，家洁师应被阻止接单。

## 3. 风险订单展示

- [ ] 低风险公开订单仍出现在家洁师可接订单列表。
- [ ] high / critical 风险订单不出现在普通家洁师可接订单列表。
- [ ] 住户本人仍能在自己的订单列表中看到订单，不因公开列表过滤而丢失。
- [ ] 风险字段不会向普通用户暴露内部原因明细。

## 4. 接单与指派边界

- [ ] BLOCK 决策的订单不能被家洁师接单。
- [ ] RESTRICT 决策的订单提示需要平台复核，不应直接进入响应或履约流程。
- [ ] 高可疑 user-cleaner 组合不能被直接指派，或提示需要平台复核。
- [ ] blocked 家洁师不能被住户指派。
- [ ] 正常家洁师仍可响应低风险公开订单。

## 5. 行为图谱和异常模式

- [ ] 同一住户和家洁师多次取消后重新预约时，风险分值上升。
- [ ] 同一住户和家洁师异常高频成功配对时，可被标记为可疑配对。
- [ ] 多账号围绕同一家洁师反复取消时，可被识别为风险模式。
- [ ] 风险识别不应影响无关订单的正常展示和操作。

## 6. 自动治理规则

- [ ] 家洁师 24 小时内取消达到 3 次时，账号应进入临时冻结或复核状态。
- [ ] 7 天内投诉达到 2 次时，应标记需要平台复核。
- [ ] blocked 家洁师不能接单。
- [ ] 低信任家洁师仍不应看到客户隐私字段。

## 7. 管理员操作

- [ ] 管理员可执行 blockCleaner。
- [ ] 管理员可执行 unblockCleaner。
- [ ] 管理员可执行 adjustTrustScore。
- [ ] 管理员可执行 flagOrder。
- [ ] 普通用户不能调用上述管理员操作。
- [ ] 管理员操作会写入 auditLogs，且不包含手机号、详细地址、证件 fileID 等敏感原文。
