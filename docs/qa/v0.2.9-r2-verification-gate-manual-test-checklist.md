# v0.2.9-r2 Verification Gate 人工测试清单

## 家洁师准入门禁

- [ ] 家洁师准入页提交空资料时，云函数返回 `MISSING_REQUIRED_FIELDS`，不会进入审核队列。
- [ ] 缺少身份证号时，不能提交准入申请。
- [ ] 缺少手机号、健康凭证记录或培训状态时，不能提交准入申请。
- [ ] 身份证号格式错误时，不能提交准入申请。
- [ ] 手机号格式错误时，不能提交准入申请。
- [ ] 完整填写真实姓名、身份证号、手机号、健康凭证记录、培训状态后，可以进入审核队列。

## 审核队列

- [ ] `cleanerVerificationQueue` 集合中能看到 queued 记录。
- [ ] 管理员准入列表优先显示脱敏姓名或昵称，而不是只显示 openid。
- [ ] 管理员准入列表数据中包含可读 `displayName`，页面展示不以 openid 作为主标题。
- [ ] 管理员调用 `adminReviewCleanerVerification` 后，队列状态同步为 approved/rejected。
- [ ] 未通过系统校验的记录不能被管理员直接 approve。
- [ ] 审批通过后，家洁师 `launchEligible` 和 `canReceiveOrders` 为 true。
