- [ ] 杭州报价不能用于上海订单。
- [ ] 使用 quoteId 下单时订单必须有明确服务城市，缺少城市应失败。

- [ ] 住户 waiting_confirm 响应列表仍可选择家洁师，但不显示 `platformFee` 或 `cleanerIncome`。

- [ ] 未选择服务地址前，下单页不展示本地 fallback 金额，应提示“请选择服务地址后获取报价”。

# v0.2.3-r3 补充检查

- [ ] 无 quoteId 下单时，客户端传 `couponDiscount` / `couponCode` 不能改变服务端计算价格。
- [ ] 无 quoteId 下单时，客户端传 `customerPayAmount` / `orderAmount` / `amount` / `cleanerIncome` 不能改变订单金额或阿姨收入。
- [ ] 无 quoteId 下单时，客户端伪造 `pricingSnapshot` / `priceRuleVersion` 不会被写入订单，订单仍使用服务端 fallback quote。
- [ ] `locationSnapshot` 缺少 city 但顶层 `city` 存在时，订单 `city` 和 `locationSnapshot.city` 正确写入。
- [ ] `locationSnapshot.city` 和顶层 `city` 都缺失时，下单失败且不创建订单。
- [ ] quoteId 正常路径和无 quoteId fallback 路径都使用服务端报价，不信任前端金额字段。

# v0.2.3-r4 补充检查

- [ ] pricing domain 直接调用 `calculateQuote` 时，dirty input 中的 `couponDiscount` / `customerPayAmount` / `orderAmount` 不会污染报价。
- [ ] `sanitizePricingInput` 是 pricing domain 的统一白名单入口，不透传客户端原始字段。
- [ ] `createPricingQuote` 和 `createOrder` fallback 都使用同一个 pricing 输入清洗逻辑。
- [ ] 开荒保洁使用 `areaSqm` 或 `areaSize` 得到的服务端报价一致。
- [ ] 无 quoteId fallback 路径与先 `createPricingQuote` 再下单的金额口径一致。

# v0.2.3 微信开发者工具人工测试清单

- [ ] 确认当前分支是 `feature/v0.2.3-pricing-engine-and-subsidy-accounting`。
- [ ] 确认已拉取最新代码并重新导入或刷新微信开发者工具项目。
- [ ] 确认云函数 `quickstartFunctions` 已部署或本地调试可用。
- [ ] 准备住户账号、家洁师账号，如可用准备管理员账号。
- [ ] 确认本轮不测试真实微信支付、退款、结算。
- [ ] 确认正式上线前仍必须执行微信开发者工具真实编译和完整人工测试。

## 1. 小程序启动和基础回归

- [ ] 小程序可正常启动，无白屏。
- [ ] 首页、订单列表、订单详情、Profile 页面可正常打开。
- [ ] 下单页可正常打开，无 JS ReferenceError。
- [ ] 控制台无页面路径缺失错误。
- [ ] 前端没有 `ENABLE_MOCK_PAYMENT` 相关报错。
- [ ] 页面中没有“平台托管中”“支付到平台托管”“费用已由平台托管”。
- [ ] 页面中没有“百万保障”“全额赔付”“已投保”。

## 2. 城市报价检查

- [ ] 上海市日常保洁 2 小时报价当前价为 79，列表价为 98。
- [ ] 杭州市日常保洁 3 小时报价当前价为 109。
- [ ] 无锡市日常保洁 4 小时报价当前价为 132。
- [ ] 哈尔滨市日常保洁 5 小时报价当前价为 155。
- [ ] 切换城市后报价会刷新，不沿用上一个城市 quoteId。
- [ ] 报价刷新失败时页面有明确提示，不崩溃。

## 3. 服务类型和时长报价

- [ ] 日常保洁 2/3/4/5 小时均能获取服务端报价。
- [ ] 深度保洁 2/3/4/5 小时均能获取服务端报价。
- [ ] 家务整理 2/3/4/5 小时均能获取服务端报价。
- [ ] 切换服务类型后报价会刷新。
- [ ] 切换时长后报价会刷新。
- [ ] 前端展示列表价、当前价、优惠说明，但不展示平台毛利、cashBurn、platformSubsidy。

## 4. 开荒保洁面积报价

- [ ] 选择开荒保洁后显示面积输入。
- [ ] 未填写面积时不能获取有效报价，并提示填写面积。
- [ ] 面积 80㎡ 时按面积报价，不按小时报价。
- [ ] 面积 40㎡ 时按 60㎡ 起步面积计费。
- [ ] quote 或页面文案能体现开荒保洁按面积计价、60㎡ 起计。
- [ ] durationHours 如仍显示，仅作为预约时长参考，不应影响开荒保洁计价。

## 5. 下单 quoteId 流程

- [ ] 下单页选择城市、服务、时长或面积后会获取服务端报价。
- [ ] 提交订单时传入 quoteId。
- [ ] quote 过期或失效时下单失败，并提示重新获取报价。
- [ ] 修改城市、服务类型、时长、面积或指定家洁师后，会重新获取 quote。
- [ ] 创建订单成功后订单详情价格与下单页服务端报价一致。
- [ ] 前端修改本地金额字段不会改变订单最终金额。

## 6. 优惠和收入保护

- [ ] 页面不向普通住户展示阿姨收入、平台费率、平台补贴、毛利或 cashBurn。
- [ ] 如测试 coupon/discount 场景，住户当前价降低时家洁师预计收入不应被压低。
- [ ] 家洁师端如展示预计收入，仅应在相关订单中显示。
- [ ] 非相关家洁师看不到其他订单的 cleanerIncome。

## 7. 订单详情和订单卡片价格展示

- [ ] 订单详情优先显示 pricingSnapshot 中的用户可见价格。
- [ ] 订单卡片价格展示与订单详情一致。
- [ ] 普通住户订单详情不显示 cashBurn、platformSubsidy、marginWarning。
- [ ] 未参与家洁师看公开订单时不显示 customerOpenid、note、完整 responses、价格内部字段。
- [ ] 已确认接单家洁师仅在相关订单中看到必要收入信息。
