# v0.2.2 微信开发者工具人工测试清单

## 测试前准备

- [ ] 确认当前分支是 `feature/v0.2.2-order-protection-and-after-sales`。
- [ ] 确认已拉取最新代码。
- [ ] 在微信开发者工具中重新导入或刷新项目。
- [ ] 确认云函数 `quickstartFunctions` 已部署或本地调试可用。
- [ ] 准备住户账号、家洁师账号，如可用再准备管理员账号。
- [ ] 确认本次不测试真实微信支付、真实退款、真实结算、真实保险理赔。
- [ ] 正式上线前仍必须执行本清单并记录微信开发者工具版本和基础库版本。

## 1. 基础启动

- [ ] 小程序可正常启动，无白屏。
- [ ] 底部 Tab 可切换。
- [ ] Profile、订单列表、订单详情、家洁师列表/详情可正常打开。
- [ ] 控制台无明显 `ReferenceError`。
- [ ] 控制台无页面路径缺失错误。

## 2. 保障规则页面

- [ ] Profile 或订单详情可进入服务保障页。
- [ ] 服务保障页可加载保障方案。
- [ ] 页面出现“保障范围以实际保险合同和平台规则为准。”。
- [ ] 页面说明退款/补偿需由平台人工确认处理。
- [ ] 页面不出现“百万保障”。
- [ ] 页面不出现“全额赔付”。
- [ ] 页面不出现“已投保”。

## 3. 服务标准页面

- [ ] 订单详情可进入服务标准页。
- [ ] 服务标准页展示当前服务类型。
- [ ] 服务标准页展示包含项目。
- [ ] 服务标准页展示不包含项目。
- [ ] 服务标准页展示住户提示。
- [ ] 配置缺失时页面不崩溃。

## 4. 客户申请售后

- [ ] 住户可从订单详情进入“申请售后”。
- [ ] 可选择返工、退款/补偿、投诉、财损等类型。
- [ ] 描述为空时有提示。
- [ ] 可填写描述并提交。
- [ ] 可填写申请金额，但页面明确为平台人工确认。
- [ ] 图片 fileID 留空时仍可提交。
- [ ] 提交成功后进入工单详情或有明确提示。
- [ ] 创建后订单详情或订单卡片可看到简短售后状态。

## 5. 家洁师异常报备

- [ ] 已确认接单家洁师可从订单详情进入“异常报备”。
- [ ] 被指派家洁师可在指派订单中报备异常。
- [ ] 未参与订单的家洁师不能报备异常。
- [ ] 异常报备提交成功后生成售后/异常工单。
- [ ] 其他未参与家洁师看不到该异常工单。

## 6. Claim 列表和详情

- [ ] Profile 可进入“售后与反馈”列表。
- [ ] 订单详情可进入该订单的售后记录。
- [ ] 住户只能看到自己订单相关工单。
- [ ] 家洁师只能看到自己参与订单相关工单。
- [ ] 工单详情可展示类型、状态、描述和关联订单摘要。
- [ ] 工单详情中的订单信息不暴露无关手机号、微信号、详细地址、门禁信息。

## 7. 服务完成证明

- [ ] 家洁师完成服务时可提交完成照片。
- [ ] 完成照片提交不改变真实支付/结算能力。
- [ ] 图片数量超过限制时有提示或提交失败。
- [ ] 未参与家洁师不能提交服务证明。
- [ ] 住户可在订单详情看到履约阶段允许展示的完成照片。

## 8. 权限隔离

- [ ] 非订单参与人不能创建售后工单。
- [ ] 非订单参与人不能查看售后工单详情。
- [ ] 普通用户不能更新工单状态。
- [ ] 管理员状态更新如可测试，应只改变工单状态，不触发真实退款或赔付。
- [ ] 客户投诉内容不暴露给未参与家洁师。

## 9. 文案检查

- [ ] 小程序前端没有“模拟支付”按钮。
- [ ] 页面不调用 `mockPayOrder`。
- [ ] 页面不出现“平台托管中”。
- [ ] 页面不出现“支付到平台托管”。
- [ ] 页面不出现“费用已由平台托管”。
- [ ] 页面不出现“百万保障”。
- [ ] 页面不出现“全额赔付”。
- [ ] 页面不出现“已投保”。
- [ ] 退款相关文案为“当前支付能力待接入，退款/补偿需由平台人工确认处理。”或等价克制表达。

## 10. 订单卡片售后状态

- [ ] 创建售后后，订单卡片可展示“已提交反馈”或“售后处理中”。
- [ ] 订单卡片状态、距离、评价状态、售后状态不重叠。
- [ ] 长服务标题不会撑破卡片。
- [ ] 长地址不会挤压右侧状态。

## 11. v0.2.1 隐私回归检查

- [ ] public order 不返回 note。
- [ ] public order 不返回 customerOpenid。
- [ ] public order 不返回完整 responses。
- [ ] 未选中家洁师看不到客户手机号、微信号、详细地址、门禁备注。
- [ ] 客户未确认/未支付阶段看不到家洁师手机号/微信号。
- [ ] recentReviews 不显示 customerOpenid、cleanerOpenid、orderId 或内部审核字段。
- [ ] 家洁师公开资料不显示 phone、wechatContact、lastLocation、证件 fileID、保单号。

## 12. 已知不测试 / 不通过但可接受项

- [ ] 真实微信支付未接入。
- [ ] 真实退款未接入。
- [ ] 家洁师结算未接入。
- [ ] 真实保险理赔未接入。
- [ ] CloudBase 生产数据库规则未复核。
- [ ] 微信开发者工具真实编译本轮如未执行，正式上线前仍是阻塞项。
