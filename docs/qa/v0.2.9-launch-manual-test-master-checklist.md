# v0.2.9 上线阻塞与人工 QA 总清单

## 1. 微信支付

- [ ] 未配置微信支付时，生产环境创建支付意图失败且不生成假支付记录。
- [ ] 生产环境不能启用 `manual_stub`。
- [ ] 配置微信支付后，订单详情可生成 JSAPI 支付参数。
- [ ] 支付回调缺签名时失败。
- [ ] 重复支付不会创建多条已支付记录。

## 2. 退款与结算

- [ ] 客户可以提交退款请求，但不能直接触发真实退款。
- [ ] 非管理员不能调用真实退款提交。
- [ ] 退款金额不能超过订单实付金额。
- [ ] 结算只生成 `payoutRecords` 待人工打款，不执行资金操作。
- [ ] 对账页面只显示人工复核信息。

## 3. CloudBase 数据库权限

- [ ] `paymentCallbacks`、`auditLogs`、`settlements`、`payoutRecords` 仅管理员或云函数可访问。
- [ ] `cleanerVerifications` 原始证件 fileID 不向普通用户公开。
- [ ] `insurancePolicies` 保单号和保单文件只允许管理员读取。
- [ ] 按 `docs/launch/09_CLOUDBASE_PRODUCTION_SECURITY_CHECKLIST.md` 逐项复核。

## 4. 微信开发者工具

- [ ] 按 `docs/qa/WECHAT_DEVTOOLS_MANUAL_COMPILE_AND_TEST.md` 完成编译。
- [ ] 完成真机预览。
- [ ] 确认 AppID、基础库、云函数环境均正确。

## 5. 家洁师准入

- [ ] 未通过上线准入的家洁师不能接单。
- [ ] 未通过上线准入的家洁师不出现在推荐列表。
- [ ] 家洁师可提交准入资料。
- [ ] 管理员可审核准入资料。
- [ ] 公开家洁师 badge 不显示证件 fileID、保单号或保单原件。
- [ ] 保险文案只显示“保障范围以实际保险合同和平台规则为准。”或“保险能力待接入/以实际订单保障页为准。”。

## 6. 运营控制台

- [ ] 非管理员不能打开运营控制台数据。
- [ ] 管理员可查看订单、退款、家洁师准入、结算对账入口。
- [ ] 控制台不展示客户手机号、详细地址、证件 fileID、保单号。

## 7. 回归检查

- [ ] 小程序不包含 `ENABLE_MOCK_PAYMENT`。
- [ ] 小程序不调用 `mockPayOrder`。
- [ ] 页面中没有“平台托管中”“支付到平台托管”“费用已由平台托管”。
- [ ] 页面中没有“百万保障”“全额赔付”“已投保”。
- [ ] v0.2.1 隐私脱敏仍然有效。
- [ ] v0.2.2 claim/review/serviceProof 脱敏仍然有效。
- [ ] v0.2.3 pricing quote 仍然由服务端可信生成。
