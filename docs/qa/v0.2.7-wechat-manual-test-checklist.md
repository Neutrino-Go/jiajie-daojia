# v0.2.7 微信开发者工具人工测试清单

## 测试前准备

- [ ] 确认当前分支是 `feature/v0.2.7-autonomous-ops`。
- [ ] 确认 v0.2.6 已合并到 dev。
- [ ] 确认本版本只做可控自动运营，不接真实支付。
- [ ] 确认本版本不改变订单状态机核心逻辑。
- [ ] 确认本版本不改变 pricing / settlement / claim 系统。
- [ ] 确认微信开发者工具已刷新项目。
- [ ] 确认云函数 quickstartFunctions 可本地调试或已部署测试环境。

## 1. OBSERVE

- [ ] 系统可读取 metrics / anomalies / insights / recommendations。
- [ ] 读取过程不修改订单。
- [ ] 读取过程不修改 pricing quote。
- [ ] 读取过程不修改 payment / settlement / payout。
- [ ] 读取过程不修改 claim。

## 2. PLAN

- [ ] 风险上升时能生成 cleaner ranking 调整计划。
- [ ] 取消率上升时能生成 supply throttling 计划。
- [ ] GMV 下降时能生成 pricing weight adjustment 计划。
- [ ] 计划结果不包含真实金额调整、退款、结算、打款动作。
- [ ] actionPlan 中每个动作都标记为 controlled / reversible。

## 3. SIMULATE

- [ ] 每个 action 都先生成模拟结果。
- [ ] 模拟结果包含 GMV impact。
- [ ] 模拟结果包含 cancellation impact。
- [ ] 模拟结果包含 trust impact。
- [ ] 模拟结果包含 risk impact。
- [ ] 模拟结果包含 confidence score。
- [ ] 模拟不会写入业务数据。

## 4. GUARD

- [ ] money-related action 被 REJECT。
- [ ] payment-related action 被 REJECT。
- [ ] settlement-related action 被 REJECT。
- [ ] payout-related action 被 REJECT。
- [ ] refund-related action 被 REJECT。
- [ ] high risk action 未审批时为 NEED_APPROVAL。
- [ ] allowlist 外动作被 REJECT。

## 5. EXECUTE

- [ ] 仅允许执行 ranking adjustment。
- [ ] 仅允许执行 pricing weight adjustment，且不修改真实金额。
- [ ] 仅允许执行 supply throttling。
- [ ] 仅允许执行 visibility adjustment。
- [ ] rejected action 不进入 appliedActions。
- [ ] NEED_APPROVAL action 未审批时不执行。
- [ ] 执行结果有 rollbackPlan。
- [ ] rollback 后恢复执行前状态。

## 6. 资金和状态机边界

- [ ] 不创建 payment intent。
- [ ] 不处理 payment callback。
- [ ] 不执行 force refund。
- [ ] 不执行 settle order。
- [ ] 不执行 adjust payout。
- [ ] 不修改订单主状态机。
- [ ] 不修改售后 claim 状态。

## 7. v0.2.1 - v0.2.6 回归检查

- [ ] 前端没有 `ENABLE_MOCK_PAYMENT`。
- [ ] 前端没有调用 `mockPayOrder`。
- [ ] 页面没有“平台托管中 / 支付到平台托管 / 费用已由平台托管”。
- [ ] 页面没有“百万保障 / 全额赔付 / 已投保”。
- [ ] public order 仍不暴露 note / customerOpenid / 完整 responses。
- [ ] claim / review / serviceProof 脱敏仍正常。
- [ ] quote 仍由服务端生成或服务端 fallback 生成。
- [ ] ops intelligence 仍是只读分析层。

## 8. 已知不测试 / 上线前阻塞

- [ ] 微信开发者工具真实编译仍需正式上线前执行。
- [ ] CloudBase 生产数据库规则和部署权限仍需复核。
- [ ] 真实微信支付、退款、结算仍未实现。
- [ ] 真实保险理赔仍未实现。
- [ ] 完整后台运营控制台仍未实现。
