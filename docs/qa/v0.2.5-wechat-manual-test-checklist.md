# v0.2.5 微信开发者工具人工测试清单

## 测试前准备

- [ ] 确认当前分支是 `feature/v0.2.5-platform-ops`。
- [ ] 确认已拉取最新代码并重新打开微信开发者工具项目。
- [ ] 确认 `quickstartFunctions` 云函数已部署或本地调试配置可用。
- [ ] 准备住户账号、家洁师账号和管理员账号。
- [ ] 确认真实微信支付未接入，本版本只验证支付意图、回调幂等和运营闭环。
- [ ] 确认真实退款、银行打款、税务和真实保险理赔未接入。

## 1. 基础启动回归

- [ ] 小程序可正常启动，无白屏。
- [ ] 首页、订单列表、订单详情、Profile 可正常加载。
- [ ] 控制台无明显 `ReferenceError`。
- [ ] 前端没有 `ENABLE_MOCK_PAYMENT`。
- [ ] 前端不调用 `mockPayOrder`。
- [ ] 页面不出现“平台托管中”“支付到平台托管”“费用已由平台托管”。
- [ ] 页面不出现“百万保障”“全额赔付”“已投保”。

## 2. 支付意图和重复支付检查

- [ ] 住户在待支付订单上创建支付意图不崩溃。
- [ ] 同一订单、同一幂等键重复创建支付意图，只返回同一笔支付意图。
- [ ] 重复支付不会创建多条 `paymentIntents`。
- [ ] 已支付回调再次进入时应按重复事件处理，不重复改写订单。
- [ ] 金额不一致的支付回调应失败。
- [ ] 支付成功后订单兼容进入当前履约前状态，且 `opsState` 进入 `PAID`。
- [ ] 本版本不应展示真实微信支付收银台。

## 3. 结算和 payout 检查

- [ ] 管理员可对已完成且已记录支付状态的订单创建结算记录。
- [ ] 结算金额按 `cleanerIncome - penalty + bonus` 计算。
- [ ] `penalty` 增加时，家洁师 payout 减少。
- [ ] `bonus` 增加时，家洁师 payout 增加。
- [ ] 结算完成后订单记录 `settlementStatus` 和 `opsState`。
- [ ] 管理员可调整 payout，普通用户不可调整。
- [ ] 本版本不应触发真实银行打款。

## 4. SLA 检查

- [ ] 延迟超过 30 分钟时可计算 penalty。
- [ ] 接单后取消可计算 penalty。
- [ ] no-show 可计算 penalty。
- [ ] 多个 SLA 原因叠加时 penalty 合计正确。
- [ ] SLA penalty 不改变订单主状态机，只影响结算计算。

## 5. Admin Ops 最小控制台能力

- [ ] 管理员可查看订单列表。
- [ ] 管理员可执行人工退款标记。
- [ ] 人工退款只更新平台记录，不应调用真实支付退款。
- [ ] 管理员可调整 payout。
- [ ] 管理员可沿用 v0.2.4 的家洁师 block/unblock 能力。
- [ ] 普通住户和家洁师不能调用 admin ops actions。

## 6. 对账和异常检测

- [ ] 每日订单对账可生成 report。
- [ ] 已支付支付意图但订单未标记支付时，对账可发现异常。
- [ ] 已结算订单缺少 settlement 时，对账可发现异常。
- [ ] payout 金额与公式不一致时，对账可发现异常。
- [ ] 对账结果不暴露手机号、微信号、详细地址、门禁、证件 fileID。

## 7. v0.2.1 隐私回归

- [ ] 公开订单不返回客户手机号、微信号、详细地址、精确坐标、备注。
- [ ] 非参与方看不到 `customerOpenid` 和完整 `responses`。
- [ ] 家洁师公开资料不返回手机号、微信号、证件 fileID、保单号。
- [ ] 公开评价不返回 `customerOpenid`、`cleanerOpenid`、`orderId` 或内部审核字段。

## 8. v0.2.2 售后回归

- [ ] 非订单参与人不能创建或查看售后 claim。
- [ ] `waiting_payment` 阶段的 selected cleaner 看不到客户 claim。
- [ ] 非履约视角看不到 `serviceProof`、完成照片、`serviceProofImageUrls`。
- [ ] 家洁师异常报备仍只允许异常/安全风险语义。

## 9. v0.2.3 报价回归

- [ ] 下单仍使用服务端 quote 或服务端 fallback quote。
- [ ] 客户端传入金额、`couponDiscount`、`pricingSnapshot` 不能改价。
- [ ] quote 不能跨城市使用。
- [ ] quote 已使用后不能重复下单。
- [ ] 客户响应列表不显示 `platformFee` 或 `cleanerIncome`。

## 10. v0.2.4 风控回归

- [ ] blocked cleaner 不能接单。
- [ ] high risk / BLOCK 订单不在可接订单列表展示。
- [ ] trust/risk/graph 决策不影响 pricing、claim 和 review 脱敏。

## 已知不测试 / 上线前阻塞项

- [ ] 真实微信支付未接入。
- [ ] 真实微信退款未接入。
- [ ] 家洁师真实结算和银行打款未接入。
- [ ] 税务系统未接入。
- [ ] CloudBase 生产数据库规则和部署权限未复核。
- [ ] 微信开发者工具真实编译仍需正式上线前执行。
