# v0.2.1 微信开发者工具人工测试清单

## 测试前准备

- [ ] 确认当前分支是 v0.2.1 PR 分支。
- [ ] 确认已拉取最新代码。
- [ ] 在微信开发者工具中重新导入或刷新项目。
- [ ] 确认云函数 quickstartFunctions 已部署或本地调试配置可用。
- [ ] 确认测试账号至少包含：
  - 住户账号
  - 家洁师账号
  - 如可用，管理员账号
- [ ] 确认当前环境不是 production，或已清楚 production 下 mock/seed 不可用。
- [ ] 确认本次不测试真实支付，因为真实微信支付未接入。

## 1. 小程序启动和基础页面

- [ ] 小程序可正常启动，无白屏。
- [ ] 首页可正常加载。
- [ ] 底部 Tab 可正常切换。
- [ ] Profile 页面可正常加载。
- [ ] 订单列表页可正常加载。
- [ ] 家洁师列表/详情页可正常加载。
- [ ] 控制台无明显 JS ReferenceError。
- [ ] 控制台无页面路径缺失错误。

## 2. 合规和帮助入口

- [ ] Profile 页可进入用户协议。
- [ ] Profile 页可进入隐私政策。
- [ ] Profile 页可进入平台交易规则。
- [ ] Profile 页可进入服务保障规则。
- [ ] Profile 页可进入退款取消规则。
- [ ] Profile 页可进入个人信息删除/注销说明。
- [ ] 下单页底部可查看用户协议和隐私政策。
- [ ] 页面中没有“百万保障”“全额赔付”“已投保”等未经验证承诺。
- [ ] 页面中没有“暂未开放”死链文案。

## 3. 支付和托管文案检查

- [ ] 小程序前端没有“模拟支付”按钮。
- [ ] 订单详情没有调用 mockPayOrder。
- [ ] 页面中没有“平台托管中”。
- [ ] 页面中没有“支付到平台托管”。
- [ ] 页面中没有“费用已由平台托管”。
- [ ] 待支付状态显示“支付能力待接入”或“试运营流程待平台确认”等克制文案。
- [ ] 点击支付相关入口不会崩溃，应提示支付能力待接入。

## 4. 住户下单流程

- [ ] 住户可以进入下单页。
- [ ] 可选择服务类型。
- [ ] 可选择服务时长。
- [ ] 可选择服务时间。
- [ ] 可填写地址、手机号、备注。
- [ ] 可查看价格展示。
- [ ] 可创建公开订单。
- [ ] 可创建指派家洁师订单，如该功能当前可用。
- [ ] 创建订单后进入订单详情不崩溃。
- [ ] 住户本人在 waiting_response / waiting_payment 等早期状态可以看到自己填写的地址和联系方式。
- [ ] 订单详情不显示真实支付托管承诺。

## 5. 家洁师接单流程

- [ ] 家洁师可以进入可接订单列表。
- [ ] 可接订单列表不显示客户手机号。
- [ ] 可接订单列表不显示客户微信号。
- [ ] 可接订单列表不显示详细门牌地址。
- [ ] 可接订单列表不暴露 customerOpenid。
- [ ] 家洁师可查看订单详情。
- [ ] 未响应家洁师可看到“响应订单”入口。
- [ ] 已响应家洁师再次进入订单详情，不应再次显示“响应订单”按钮。
- [ ] 已响应但未被选择的家洁师看不到客户手机号、微信号、详细地址。
- [ ] 已确认接单家洁师在确认履约阶段可以看到履约必要联系方式。
- [ ] 家洁师端订单列表无明显布局错乱。

## 6. 住户选择家洁师流程

- [ ] 住户可在 waiting_confirm 状态看到响应列表。
- [ ] 住户可看到家洁师公开资料，但不应看到不必要内部字段。
- [ ] 住户未支付/未确认履约前，不应提前看到家洁师手机号/微信号。
- [ ] 住户选择家洁师后，状态变化符合当前试运营流程。
- [ ] 如果支付能力未接入，订单不会误导用户认为资金已托管。
- [ ] 选择家洁师流程不因 cleanerId / _openid 兼容问题失败。

## 7. 家洁师公开资料和评价

- [ ] 家洁师列表正常展示头像、昵称、评分、服务区域等公开信息。
- [ ] 家洁师详情页正常展示公开信息。
- [ ] 普通住户看不到家洁师手机号。
- [ ] 普通住户看不到家洁师微信号。
- [ ] 普通住户看不到家洁师精确位置。
- [ ] 普通住户看不到证件 fileID、保单号、内部审核字段。
- [ ] recentReviews 可正常显示评分、内容、图片、脱敏用户名、服务类型和时间。
- [ ] recentReviews 不显示 customerOpenid、cleanerOpenid、orderId 或内部审核字段。

## 8. 客服 / support ticket

- [ ] Profile 页可进入客服/反馈页面。
- [ ] 订单详情页可进入客服/反馈页面。
- [ ] 可提交普通反馈。
- [ ] 可提交关联订单的反馈。
- [ ] 缺少问题类型或描述时有合理提示。
- [ ] 非订单参与人不能用别人的 orderId 创建工单。
- [ ] 提交成功后有明确提示。
- [ ] 提交失败时不崩溃。

## 9. Profile 和假数据检查

- [ ] Profile 页面无“客服暂未开放”。
- [ ] Profile 页面无“反馈暂未开放”。
- [ ] Profile 页面无“优惠券暂未开放”。
- [ ] 如仍存在硬编码统计，请记录位置和截图，作为后续 launch-hardening 问题，不在 v0.2.1 中临时大改。
- [ ] 用户角色切换或身份展示正常。

## 10. 订单卡片 UI 回归检查

- [ ] 住户端订单卡片状态、距离、评价状态无明显重叠。
- [ ] 家洁师端可接订单卡片状态、距离无明显重叠。
- [ ] 长服务标题不会撑破卡片。
- [ ] 长地址不会挤压右侧状态。
- [ ] 已完成 / 已评价 / 距离 / 更多按钮布局可接受。
- [ ] 可接订单 / 距离布局可接受。
- [ ] 如果仍有布局问题，请截图并记录具体页面和订单状态，作为后续 UI 修复任务。

## 11. 安全和隐私重点检查

- [ ] 未参与订单的家洁师看不到 customerOpenid。
- [ ] 未参与订单的家洁师看不到完整 responses。
- [ ] 已响应但未被选择的家洁师只能看到自己的 myResponse。
- [ ] 客户本人能看到自己的完整订单信息。
- [ ] 已确认接单家洁师只能看到履约必要字段。
- [ ] 普通住户不能看到家洁师敏感字段。
- [ ] 公开评价不暴露订单 ID 或用户 openid。
- [ ] 控制台日志不应出现手机号、详细地址、证件 fileID 等敏感原文。

- [ ] 退款未接入。
