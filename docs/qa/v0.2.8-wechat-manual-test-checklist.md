# v0.2.8 微信开发者工具人工测试清单

## 测试前准备

- [ ] 确认当前分支是 `feature/v0.2.8-autonomous-system`。
- [ ] 确认 v0.2.7 已合并到 dev。
- [ ] 确认本版本只做自我优化 / 自我修正 / 自我闭环策略层。
- [ ] 确认本版本不接真实支付。
- [ ] 确认本版本不改变订单状态机。
- [ ] 确认本版本不改变 pricing / claim / settlement / trust / risk 基础结构。
- [ ] 确认微信开发者工具已刷新项目。

## 1. Feedback Loop

- [ ] actionResult 可生成 expectedImpact。
- [ ] actionResult 可生成 actualImpact。
- [ ] deviationScore 可正常计算。
- [ ] deviationScore 超过阈值时触发 optimization。
- [ ] feedback 生成不修改原始 actionResult。

## 2. Self Evaluation

- [ ] 系统可生成 revenueScore。
- [ ] 系统可生成 riskScore。
- [ ] 系统可生成 userSatisfactionScore。
- [ ] 系统可生成 stabilityScore。
- [ ] systemHealthScore 在 0-100 范围内。
- [ ] evaluation 不修改 metrics / anomalies。

## 3. Strategy Optimizer

- [ ] cancellation 上升时建议 tighten cleaner selection。
- [ ] GMV 下降时建议 adjust visibility。
- [ ] risk 上升时建议 lower exposure of low trust cleaners。
- [ ] optimizedPolicySet 不包含真实价格金额、退款、结算、打款动作。

## 4. Adaptive Policy

- [ ] feedback deviation 会降低 riskThreshold 或收紧策略。
- [ ] evaluation 健康度较低时策略更保守。
- [ ] cleanerRankingFactor 可根据策略建议调整。
- [ ] supplyThrottleLevel 可根据低信任曝光建议调整。
- [ ] 每次 adapt 都生成 rollbackSnapshot。
- [ ] adaptive policy 不修改输入 currentPolicy。

## 5. System Governor

- [ ] systemHealthScore 低于阈值时 freeze autonomy。
- [ ] freeze 后 policySet.autonomyEnabled 为 false。
- [ ] governor 可 rollback policies。
- [ ] override adaptive policies 必须有 approval。
- [ ] 未审批 override 应失败。
- [ ] safety rules 会清空 paymentAction。
- [ ] safety rules 会清空 settlementAction。
- [ ] safety rules 会清空 payoutAction。
- [ ] safety rules 会清空 refundAction。

## 6. Full Loop

- [ ] 闭环顺序为 Observe -> Decide -> Execute -> Feedback -> Evaluate -> Optimize -> Adapt。
- [ ] feedback 异常可进入 evaluation。
- [ ] evaluation 可进入 optimizer。
- [ ] optimizer 输出可进入 adaptive policy。
- [ ] adaptive policy 输出最终经过 governor。
- [ ] 闭环不修改输入 metrics / history / currentPolicy。

## 7. 资金和状态机边界

- [ ] 不创建 payment intent。
- [ ] 不处理 payment callback。
- [ ] 不执行 force refund。
- [ ] 不执行 settle order。
- [ ] 不执行 adjust payout。
- [ ] 不修改订单主状态机。
- [ ] 不修改 pricing rule 或 pricing quote。
- [ ] 不修改 claim 状态。
- [ ] 不修改 trust / risk 持久化结果。

## 8. v0.2.1 - v0.2.7 回归检查

- [ ] 前端没有 `ENABLE_MOCK_PAYMENT`。
- [ ] 前端没有调用 `mockPayOrder`。
- [ ] 页面没有“平台托管中 / 支付到平台托管 / 费用已由平台托管”。
- [ ] 页面没有“百万保障 / 全额赔付 / 已投保”。
- [ ] public order 仍不暴露 note / customerOpenid / 完整 responses。
- [ ] claim / review / serviceProof 脱敏仍正常。
- [ ] quote 仍由服务端生成或服务端 fallback 生成。
- [ ] autonomous ops v0.2.7 仍只允许低风险可回滚动作。
