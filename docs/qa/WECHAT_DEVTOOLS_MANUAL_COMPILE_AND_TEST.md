# 微信开发者工具编译与真机测试清单

## 准备

- [ ] 使用正确 AppID 打开项目，不使用测试号误判生产能力。
- [ ] 确认基础库版本符合目标上线要求。
- [ ] 拉取最新 `dev` 或当前 PR 分支代码。
- [ ] 上传云函数 `quickstartFunctions` 或确认本地调试指向正确环境。
- [ ] 确认生产环境变量不写入代码仓库。

## 编译

- [ ] 微信开发者工具点击“编译”，小程序无白屏。
- [ ] 控制台无 `ReferenceError`。
- [ ] 控制台无页面路径缺失错误。
- [ ] 云函数调用失败时页面有可理解提示。

## 真机预览

- [ ] 住户账号可登录、下单、查看订单。
- [ ] 家洁师账号可登录、查看公开订单、提交准入资料。
- [ ] 管理员账号可打开最小运营控制台。
- [ ] 支付未配置时显示“支付能力待接入”或 provider 配置缺失提示，不出现模拟支付入口。
- [ ] 支付已配置时，订单详情“立即支付”进入微信 JSAPI 支付流程。

## 发布前阻塞

- [ ] CloudBase 数据库规则已按生产环境复核。
- [ ] 微信支付回调 URL 已配置并完成签名校验。
- [ ] 退款回调和结算对账已完成真实环境验证。
- [ ] 证件、保单、服务证明图片存储权限已复核。
