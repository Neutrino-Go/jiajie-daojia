# v0.2.6 微信开发者工具人工测试清单

## 测试前准备

- [ ] 确认当前分支是 `feature/v0.2.6-ops-intelligence`。
- [ ] 确认 v0.2.5 已合并或当前分支基于 v0.2.5 最终提交。
- [ ] 确认本版本只做运营指标、异常识别、洞察和建议。
- [ ] 确认本版本不接真实支付、不退款、不结算、不修改订单状态机。
- [ ] 确认微信开发者工具已重新导入或刷新项目。
- [ ] 确认云函数 quickstartFunctions 可本地调试或已部署测试环境。

## 1. 只读边界检查

- [ ] 查看运营智能相关页面或调试入口时，订单数据不被修改。
- [ ] 查看运营智能相关页面或调试入口时，支付状态不被修改。
- [ ] 查看运营智能相关页面或调试入口时，pricing quote 不被修改。
- [ ] 查看运营智能相关页面或调试入口时，trust/risk 决策不被修改。
- [ ] 查看运营智能相关页面或调试入口时，settlement/payout 不被修改。
- [ ] 控制台没有出现资金操作、退款操作、结算操作日志。

## 2. Metrics Engine

- [ ] GMV 指标可正常计算。
- [ ] completionRate 指标可正常计算。
- [ ] cancellationRate 指标可正常计算。
- [ ] avgResponseTime 指标可正常计算。
- [ ] activeUsers 指标可正常计算。
- [ ] activeCleaners 指标可正常计算。
- [ ] trustScoreAvg 指标可正常计算。
- [ ] riskScoreAvg 指标可正常计算。
- [ ] dailyMetrics 和 weeklyMetrics 都能生成。

## 3. Anomaly Detector

- [ ] cancellationRate 上升 30% 以上时能识别异常。
- [ ] GMV 明显下降时能识别异常。
- [ ] trustScoreAvg 明显下降时能识别异常。
- [ ] riskScoreAvg 明显上升时能识别异常。
- [ ] anomaly severity 为 low / medium / high / critical 中的合理值。

## 4. System Insights

- [ ] 能生成运营异常总结。
- [ ] 能生成用户行为趋势。
- [ ] 能生成家洁师供给变化。
- [ ] 能生成风险变化趋势。
- [ ] 文案不承诺自动执行任何运营动作。

## 5. Auto Recommendation Engine

- [ ] 能生成派单权重调整建议。
- [ ] 能生成风险区域建议。
- [ ] 能生成价格建议，但不执行价格变更。
- [ ] 能生成家洁师管理建议。
- [ ] 所有建议都明确是 recommend-only。

- [ ] recentReviews 不暴露 customerOpenid / cleanerOpenid / orderId。
